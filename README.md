
# Customer Churn Analysis for Telecom Industry

## Objective
Predict customer churn in a telecom company and provide actionable insights to reduce churn using data-driven modeling and explainability tools.

## Dataset
IBM Telco Customer Churn Dataset, which includes customer account information, service usage, and churn status.

## Tools Used
- Python (Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, SHAP)
- Jupyter Notebook
- Random Forest Classifier

## Key Steps
1. Data Cleaning & Preprocessing
2. Exploratory Data Analysis
3. Feature Engineering
4. Churn Prediction using Random Forest
5. Explainability using SHAP
6. Customer Segmentation: At Risk, Loyal, Dormant

## Outputs
- `churn_predictions.csv`: Includes churn probability and predictions
- `confusion_matrix.png`: Visual performance of the model
- `churn_project_report.pdf`: Executive 2-page summary
- `churn_insights.pptx`: Slide deck with insights & strategy

## Final Notes
This analysis enables targeted interventions to improve retention by identifying key factors influencing churn.
